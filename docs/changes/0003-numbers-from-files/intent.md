# Intent: numbers-from-files

## Problem
Coming up with simlar numbers was a bad idea both in the time it takes to build and that sometimes 
it was harder than the actual homework

It would also be nice with some sound effects

## Proposed outcome
Have the levels contain the exact same numbers as the homework in that order. Perhaps sub-divide the numbers into goal sections. You will need to have solved 2/3rds of them to be able to get a key for the boss. 


## Player experience
Different levels should have different colors and themes would be nicer. Also play sounds effects when winning over the enemy.
Maybe some effects for when getting the answer right as well.
